# Quiz Anatomie S2

Application interactive de révision pour l'examen d'anatomie S2.

## Caractéristiques
- 300 questions QCM/QCS
- Correction IA en temps réel
- Mode entraînement et mode examen blanc chronométré
- Statistiques par chapitre
- Compatible mobile (installable comme une app)

## Stack
- React + Vite
- Déployé sur Vercel
- IA Claude (Anthropic)
